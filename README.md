# LeadFlow CRM

CRM comercial demostrativo creado como proyecto de portfolio para mostrar gestión de leads, oportunidades, tareas y seguimiento de ventas.

## Objetivo

Construir una aplicación CRM clara, moderna y responsive que permita visualizar el estado comercial de un negocio y gestionar oportunidades desde el primer contacto hasta el cierre.

## Bloque 1 — Demo funcional front-end

La primera versión incluye:

- Dashboard con indicadores comerciales dinámicos.
- Pipeline visual por etapas: Nuevo, Contactado, Presupuesto, Negociación y Ganado.
- Movimiento de oportunidades entre etapas mediante drag & drop.
- Botón para avanzar oportunidades de forma rápida.
- Tabla completa de leads.
- Búsqueda por cliente, empresa, email o teléfono.
- Filtro por etapa comercial.
- Alta de nuevos leads mediante formulario.
- Gestión de tareas y prioridades.
- Persistencia de datos demo con `localStorage`.
- Diseño responsive para escritorio, tablet y celular.
- Datos ficticios y seguros para demostración pública.

## Tecnologías actuales

- HTML5
- CSS3
- JavaScript vanilla
- LocalStorage
- Responsive Web Design

## Roadmap

Las siguientes etapas previstas para el portfolio son:

1. Backend/API REST.
2. Autenticación de usuarios.
3. PostgreSQL.
4. CRUD persistente de clientes y oportunidades.
5. Notas e historial de actividad.
6. Roles y responsables comerciales.
7. Métricas y reportes ampliados.
8. Integraciones externas.

## Nota de portfolio

Todos los nombres, empresas, contactos y montos incluidos son ficticios. Este repositorio es una demostración técnica y no contiene información de clientes reales.
